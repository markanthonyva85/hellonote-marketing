# HelloNote -- Keyword Prompt Shortcuts
Copy any ONE line below and paste it into a new Claude chat to instantly activate that persona.
Replace [task] with what you want done. That is all you need.

---

## HOW IT WORKS

Every keyword line does two things at once:
1. Loads the AGENT_BRIEF.md so Claude knows HelloNote fully
2. Loads the specific persona prompt for the task

You never need to remember file paths or long URLs again. Just copy the keyword line for the persona you need, paste it in a new chat, and go.
